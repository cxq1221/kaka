# 隐私说明

Kaka 采用本地优先设计。截屏、录屏、标注、OCR 结果与素材库默认只留在设备上；只有你主动导出，或明确把当前 OCR 选区发送给已配置的远程服务时，数据才会离开设备。Kaka 没有账号系统、分析、广告或遥测。

## 素材库存储

Kaka 默认在系统应用数据目录中维护一个素材库。设置可以把它复制到其他本机目录或外接盘并切换使用，原位置仍保留副本。所选位置会保存素材库索引、截图、录屏和可编辑的截图、视频工程。

如果已完成的录屏未能导入当前素材库，Kaka 会把它保留在本地恢复区，直到后续导入成功。

## 可重编辑的截图工程

对于当前版本 Kaka 创建的标注，本地素材库会同时保存可分享的压平截图、未加标注的源图，以及一份小型标注文档。源图仍可能包含在压平结果中被马赛克、文字背景或图形遮住的像素。这些工程文件只保存在 Kaka 的当前素材库中，编辑功能不会上传它们；截图移入回收站后，工程仍可恢复，永久删除该截图时才会一并移除。旧截图中已经压平的标注无法还原；重新编辑时，会以当前压平图片作为新工程的源图。

## 可重编辑的视频工程

视频剪辑会自动保存为原片旁的本地工程，包含裁剪位置、变速设置、效果时间段、标注文字和内嵌贴图。工程不会覆盖原片，原片仍可能包含在导出副本中被遮挡的信息。编辑功能不会上传工程。工程随素材库一起迁移，移入回收站后仍可恢复，永久删除原素材时才会一并移除。导出的 MP4 是独立的压平视频副本。

## 本地媒体处理

Kaka 使用操作系统媒体框架完成录屏、暂停分段合并、视频缩略图和 MP4 转 GIF。macOS 使用 AVFoundation 与 ImageIO，Windows 使用 Media Foundation 与系统图像组件，Linux 使用系统已安装的 GStreamer 插件。Kaka 不会下载或执行 FFmpeg 等第三方媒体程序；这些操作中的截屏、录屏、文件名、素材库信息、凭据和媒体内容始终留在设备上。

## 可选的同频分享

只有对图片选择「发送到同频」时，截图才会发送到同频；保存截图本身不会自动分享。Kaka 会探测 `127.0.0.1` 的 `81` 和 `8787` 端口，也可以使用设置中填写的可选地址。自定义地址仅允许 `http://` 的本机回环或私有网络主机。

Kaka 只把所选的压平图片文件发送到同频的 `/api/files` 接口，不会发送可编辑的未标注源图、标注文档、素材库索引、文字历史或其他截图。同频会把图片保存在聊天室所在设备上，并创建一条聊天记录，供已连接设备打开。该连接使用未加密的明文 HTTP，请只发送到本机或可信的局域网聊天室。

同频使用随机 `lan_identity` Cookie 标识发送者。Kaka 会把这一化名身份保存在自己的应用配置目录中，并且只在聊天室 UUID 一致时复用。它不是 Kaka 账号，也不包含用户名或凭据。图片保留时间、文件存储、下载以及保存到相册的行为由同频产品决定。

## 打开 Kaka 时检查更新

macOS 与 Windows 安装版在打开主面板时检查更新。同一次运行中，成功检查的结果缓存六小时；失败后，五分钟后的再次打开或激活面板可以重试，不使用后台定时器。设置页仍可手动点击「检查更新」。Kaka 通过 HTTPS 请求固定的公开清单 `github.com/cxq1221/kaka/releases/latest/download/latest.json`。发现新版本后，Kaka 会显示版本号和版本说明；只有点击「下载更新」才会下载，只有再点击「安装更新」才会安装。Tauri 官方更新器会使用 Kaka 内置的公钥验证下载包签名，通过后界面才允许安装。macOS 仅在你进一步点击后重启；Windows 会关闭 Kaka，由安装程序完成更新。固定的 Releases 页面只在失败时作为恢复入口显示。

更新请求会包含当前平台与版本，但不会携带截屏、录屏、文件名、素材库信息、OCR 数据、凭据、遥测或账号标识。

## 本地 OCR

Kaka 默认使用 macOS Vision、Windows.Media.Ocr 或 Linux 系统 Tesseract 进行本地文字识别。它不需要 API Key 或网络连接，图片像素不会离开设备。

## 文字历史

识别成功且非空的文字会和识别时的图片副本一起保存在当前本地素材库中。移动素材库时一并迁移；移入回收站后仍可恢复，永久删除记录时才会一起删除。历史截图的本地识别使用已保存的压平图片，不使用编辑工程的未标注源图或尚未保存的修改。文字记录保留独立快照，因此删除原截图不会删除这份文字历史。历史记录不会发送给远程服务。关闭历史截图的识别窗口后，本地识别仍会继续；若保存失败，窗口会保留可复制的结果并提示未保存。

## 可选的远程 OCR

你可以同时保存阿里云、OpenAI，或支持图片输入的 OpenAI Chat Completions 兼容服务。新建或选中配置本身不会发送数据。每次远程请求前，Kaka 都会显示配置名称、目标域名、模型、当前选区的像素尺寸与文件大小。只有明确点击可见的「发送」或「重试」按钮，才会把该选区的 PNG、简短的文字识别指令与模型名称发给对应服务。

按 Return 会让当前图片改用本地 OCR。远程请求失败后，Kaka 不会自动重试、改投其他服务或通过备用地址上传。请求不会携带整张截屏、素材库、其他屏幕区域或之前的 OCR 结果。

远程服务会按照它自己的条款和数据保留政策处理请求。自定义配置会把图片发送到确认卡上显示的目标域名；请只配置你信任的服务。

## 密钥与配置

API Key 只在 Kaka 内输入，并保存到 macOS 钥匙串、Windows 凭据管理器或 Linux Secret Service。配置 JSON 只记录名称、Base URL、模型等非敏感信息。Kaka 不会把 API Key 回传给界面、写入日志或明文配置，也不会从环境变量读取密钥。

删除配置会同时删除对应的系统凭据。你可以随时重新选择「本地 OCR」并删除远程配置，恢复为完全本地的使用方式。
